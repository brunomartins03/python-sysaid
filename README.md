# python-sysaid

Python wrapper for the SysAid REST API (`/api/v1`).

> Status: under development, not yet released.

## Installation

```bash
pip install python-sysaid
```

OAuth 1.0 support is an optional extra:

```bash
pip install "python-sysaid[oauth]"
```

## Development

```bash
python -m venv .venv && . .venv/bin/activate
pip install -e ".[dev]"
```

The endpoint reference is in [ANOTATIONS.md](ANOTATIONS.md) and the roadmap in [PLAN.md](PLAN.md).
